\section{Firmware}
\label{app:firmware}
The robot's firmware is in our GitHub repository: \url{https://github.com/gtholiveri/MonarchOfTheHill}. The contest firmware for the Particle Photon~2 is in \texttt{photon/ble\_robot}; the other folders in \texttt{photon/} hold smaller test programs, and the repository root holds our earlier firmware for the kit's ESP32 board. \tbd{Estimator.h and Autopilot.h were last changed Oct.~12--13, before the contest; ble\_robot.cpp and Capture.h were changed Oct.~23, after it, to add a high-rate data capture. \section{Raw test data}
\label{app:data}

The test data behind this report are in the \texttt{data/} folder of our repository: \url{https://github.com/gtholiveri/MonarchOfTheHill/tree/master/data}. \texttt{pitch-runs.csv} is the dashboard log of the three autonomous runs in Fig.~\ref{fig:pitch} and Table~\ref{tab:pitch} (Runs A, B and C are runs 3, 5 and 2 in the file), and \texttt{robot-measurements.csv} holds the robot's measured mass and footprint. The folder's README describes every column.
